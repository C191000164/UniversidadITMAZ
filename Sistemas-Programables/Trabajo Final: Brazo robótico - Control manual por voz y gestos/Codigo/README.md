# Código

El programa de Arduino controla los cinco servomotores mediante los joysticks físicos y los mensajes que envía la app por Bluetooth LE. Publica los ángulos de cada articulación y los muestra en el Monitor Serie a 115200 baudios.

Para abrir el programa en Arduino IDE, selecciona la placa **Arduino UNO R4 WiFi**. El proyecto usa `Servo`, `ArduinoBLE` y `EEPROM`.
