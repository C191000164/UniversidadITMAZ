# Driver de software para un relevador

## Descripción

Esta práctica consiste en preparar un driver de software para controlar un relevador desde una tarjeta Arduino. El programa permitirá activar y desactivar el relevador mediante una salida digital, con el propósito de observar cómo el código controla este dispositivo.

## Objetivos

- Comprender la función de un driver de software para un relevador.
- Organizar el programa utilizado para controlar el relevador.
- Identificar las conexiones necesarias para el montaje.
- Documentar las pruebas y el funcionamiento del sistema.
- Reunir el código, el diagrama, el reporte y el video de la práctica.
